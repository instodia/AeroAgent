# AeroAgent - Privacy-First AI Browser Automation Extension

> **AeroAgent** is a privacy-first AI agent extension for browsers designed for autonomous web task automation with zero data leakage, client-side isolation, and total user security.

---

## 🔒 Core Value Proposition (USP)
- **100% Client-Side Privacy**: Browsing sessions, cookies, and sensitive tokens remain strictly within your device's isolated runtime memory.
- **Zero Data Leakage**: No telemetry or DOM data dispatched to external servers.
- **Autonomous Task Automation**: Multi-step workflows, smart form autofill, and data extraction with human-in-the-loop approvals.
